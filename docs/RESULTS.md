# Results

Every table on this page is generated by `scripts/make_results.py` from `results/*.json`. Test set: the MVTec 3D-AD
test split of all 10 categories (good and defective samples), ground truth = Z channel of the structured-light
point maps, evaluated on valid pixels only at 400 x 400. Metrics are averaged per image, then over images.
"raw" = the model's metric output as is; "aligned" = after a per-image least-squares scale and shift fitted to the
ground truth on the valid pixels (in depth for metric models, in inverse depth for the relative model). All
timings: NVIDIA L4.
